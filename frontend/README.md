# Marvet frontend

This React/Vite application is the frontend for the Marvet MERN project. For full setup, backend configuration, integrations, development seed instructions, and validation, see the [root README](../README.md).

Install dependencies with `npm install`, start the local development server with `npm run dev`, build production assets with `npm run build`, and run ESLint with `npm run lint`.

Frontend environment variable names are listed in `.env.example`. Copy it to `.env.local` for local configuration; never put server-only secrets in a `VITE_` variable.
